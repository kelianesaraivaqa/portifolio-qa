# Casos de Teste - Login

## CT001 - Login com credenciais válidas

**Objetivo:** Verificar se o utilizador consegue entrar com credenciais válidas.

**Pré-condições:**
- O utilizador deve possuir uma conta cadastrada.

**Passos:**
1. Aceder à página de login.
2. Inserir um e-mail válido.
3. Inserir uma senha válida.
4. Clicar em Entrar.

**Resultado esperado:**
O sistema deve autenticar o utilizador e direcioná-lo para a sua conta.
**Resultado obtido:**
Não aplicavel (teste ainda não executado).

**Estado:** Não executado. (NOT RUN).
